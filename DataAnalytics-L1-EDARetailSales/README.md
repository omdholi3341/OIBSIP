# EDA on Retail Sales Data

## Project Overview
This project performs Exploratory Data Analysis (EDA) on retail sales data to identify sales trends, customer demographics, and product performance.

## Objective
The objective is to analyze retail sales data and extract meaningful business insights.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

## Analysis Performed
- Data inspection and cleaning
- Descriptive statistics
- Monthly and quarterly sales trends
- Customer demographic analysis
- Top products and revenue by category
- Correlation analysis
- Data visualizations

## Key Insights
The analysis identifies important patterns in retail sales, customer demographics, product performance, and sales trends.

## Recommendations
- Focus on high-performing products and categories.
- Analyze customer demographics for targeted marketing.
- Monitor monthly sales trends for better inventory planning.
